# 瀏覽器插件使用說明

目前的 Banana Hand 插件可以單獨使用，**不需要安裝桌面 App，也不使用 debugger**。操作介面在插件控制頁：選擇兩個分頁、選擇一組快捷鍵，再按傳送。

目前插件版本是 **0.1.24**。它還沒有出現在 Chrome Web Store 或 Firefox 附加元件商店；請從 [v0.1.24 Release](https://github.com/botio/banana-hand/releases/tag/v0.1.24) 下載。不要安裝 0.1.21 或更早的 Browser Bridge，那是需要桌面 App 的舊插件。

## 它會做什麼

- 儲存你命名的快捷鍵，例如 `Shift+B`、`Shift+S`。這是要送給網頁的按鍵，不是啟動插件的全域熱鍵。
- 讓你選擇兩個不同的一般網頁分頁，依序傳送同一組按鍵。
- 每次接受傳送後進入 **15 秒**全域冷卻。冷卻中不能再送，也不會自動重試。
- 顯示每個分頁是「已嘗試傳送」還是「失敗」。**已嘗試傳送不代表網站已執行，也不代表訂單成立或成交。**

傳送時會把目標分頁切到前景。請先在目標網站手動確認該快捷鍵有效。兩個分頁不是同時完成；可能只有一邊成功。若兩個分頁指向同一帳戶或同一商品，可能累計成兩次操作。交易用途請先用模擬帳戶。

## 選擇檔案

| 瀏覽器 | 下載 | 用途 |
| --- | --- | --- |
| Chrome | [banana-hand-chromium-0.1.24.zip](https://github.com/botio/banana-hand/releases/download/v0.1.24/banana-hand-chromium-0.1.24.zip) | 本機載入 |
| Firefox | [banana-hand-firefox-0.1.24.xpi](https://github.com/botio/banana-hand/releases/download/v0.1.24/banana-hand-firefox-0.1.24.xpi) | 暫存載入 |

不要下載 `banana-hand-chrome-webstore-*.zip`：那是商店提交包，不是本機安裝檔。不要下載 `Source code`。0.1.23 以前的 Firefox 包可能沒有工具列圖示，請用 0.1.24。

## 安裝 Chrome

需要桌面版 Chrome 118 或更新版本。

1. 解壓縮 ZIP 到不會刪除的資料夾。要選的是直接包含 `manifest.json`、`background.js`、`panel.html` 和 `icons/` 的那一層。
2. 開啟 `chrome://extensions`，打開「開發人員模式」。
3. 按「載入未封裝項目」，選擇該資料夾。
4. 確認名稱是 **Banana Hand**、版本是 **0.1.24**，且開關已開啟。
5. 點工具列的香蕉圖示，會開啟控制頁。若看不到圖示，按拼圖圖示把它釘選。

解壓縮資料夾必須留在原位。移動或刪除後，要重新載入未封裝項目。

## 安裝 Firefox

需要桌面版 Firefox 140 或更新版本。這個 XPI **尚未由 Mozilla 簽署，也尚未上架**。正式版 Firefox 不能用「從檔案安裝附加元件」永久安裝；請用暫存載入。Firefox 重新啟動後需要再載入一次。`about:debugging` 只是安裝入口，插件發送按鍵時不使用 debugger。

1. 下載 `banana-hand-firefox-0.1.24.xpi`，不要解壓縮，也不要改副檔名。
2. 開啟 `about:debugging#/runtime/this-firefox`。
3. 按「載入暫存附加元件」，選擇該 XPI。
4. 若先前裝過舊版，先在同一頁移除舊項目，再載入 0.1.24。
5. 確認工具列出現香蕉圖示。點圖示開啟控制頁。

## 第一次傳送

1. 在同一個瀏覽器設定檔開啟兩個一般 `http` 或 `https` 分頁。不要選 `chrome://`、`about:` 或插件自己的控制頁。
2. 在控制頁按「重新整理」，分別選擇分頁 A、分頁 B，再按「儲存目的地」。兩個分頁必須不同。
3. 使用預設快捷鍵，或新增一組。可直接輸入 `Shift+B`，也可按「擷取按鍵」後按下組合。
4. 在右側選擇要傳送的快捷鍵，核對兩個分頁與按鍵。
5. 按「傳送至兩個分頁」。瀏覽器會詢問這兩個分頁所在網站的存取權限；拒絕就不會傳送。不需要事先把網站寫進設定。
6. 傳送期間不要切換分頁或視窗。完成後分別檢查兩個網站的實際結果，不要只看插件訊息。

目標分頁只保留到這次瀏覽器工作階段。快捷鍵存在本機，重開瀏覽器後仍在，但要重新選擇分頁。

## 看懂結果

| 訊息 | 意思 |
| --- | --- |
| 已派送合成按鍵事件 | 插件已送出按鍵事件。網站可能忽略，不代表操作成功。 |
| 失敗／未派送 | 這次沒有確認送出。先看錯誤，不要立刻重送。 |
| 冷卻中 | 15 秒全域冷卻尚未結束。等倒數，不要重裝。 |
| 未允許網站 | 按傳送時拒絕了網站權限。再按一次傳送可重新詢問。 |

若第一個分頁可能已經執行、第二個失敗，先核對兩邊，不要把兩次都再送一次。

## 更新與移除

Chrome：下載新版 ZIP，用新檔案取代原本載入資料夾裡的內容，不要多包一層資料夾；再到 `chrome://extensions` 按「重新載入」，確認版本號。

Firefox：在 `about:debugging` 移除舊的暫存附加元件，再載入新的 XPI。

移除時在瀏覽器的擴充功能頁刪除 Banana Hand。這不會刪除你的網頁資料。舊的桌面 App 如果還裝著，可另行用作業系統解除安裝；目前插件不依賴它。
